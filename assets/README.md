# ไฟล์ต้นฉบับของแบรนด์

ไม่ได้ถูกเสิร์ฟออกไป โฟลเดอร์นี้อยู่นอก `public/` ตั้งใจให้เก็บต้นฉบับความละเอียดสูง
ไว้สร้างไฟล์ที่ใช้งานจริงใหม่ได้เมื่อต้องการ

## brand-icon.png

ไอคอนแอป 1254×1254 พื้นโปร่ง — ต้นทางของไฟล์เหล่านี้

| ไฟล์ที่สร้างจากต้นฉบับ | ขนาด | ใช้ที่ไหน |
|---|---|---|
| `public/icon-192.png` | 192×192 | หน้าจอหลัก Android |
| `public/icon-512.png` | 512×512 | splash ของ Android |
| `public/icon-maskable-512.png` | 512×512 | Android ที่ครอบหน้ากาก — ย่อภาพเหลือ 80% วางกลางบนพื้นทึบ เพราะหน้ากากกินขอบได้ถึง 20% ถ้าวางเต็มกรอบ คำว่า Smart CAUTI Care จะถูกตัด |
| `src/app/apple-icon.png` | 180×180 | หน้าจอหลัก iOS — เติมสีพื้นทับมุมโปร่ง เพราะ iOS ตัดมุมเองอยู่แล้ว ถ้าปล่อยโปร่งจะเห็นขอบดำ |

สร้างใหม่ด้วย sharp: ย่อแบบ `fit: 'contain'` แล้วบันทึกเป็น PNG palette 256 สี
เพื่อให้ไฟล์เล็กพอสำหรับเครือข่ายในหอผู้ป่วย
